# AI 能量任務

把「能量守恆」變成拉得動的東西。

高中物理的能量守恆很抽象，學生只看得到公式。這個 App 讓學生自己調整斜坡的高度、角度、質量和摩擦係數，即時看到位能、動能、熱能怎麼轉換；卡住時，內建的 AI 老師會讀取學生當下操作的數值來講解，並出練習題。

## 功能

- **三種互動模擬**：斜坡滑動、摩擦力、熱能轉換，參數可即時調整
- **能量曲線**：模擬過程中即時畫出能量變化
- **AI 老師講解**：依目前的模擬數值產生解說，不是通用答案
- **AI 出題**：練習題附解析
- **成就系統**：完成操作與答題解鎖成就

## 技術

Java · Android SDK · 自訂 View 動畫（ValueAnimator） · OpenAI API（GPT-4o-mini） · OkHttp

## 自己執行

這個專案不含任何金鑰，執行前請在 `local.properties` 加入一行：

```
OPENAI_API_KEY=你的金鑰
```

再用 Android Studio 開啟並執行。
